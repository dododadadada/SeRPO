Why segment-level process rewards matter

LEARNS WHERE OUTCOME RL CAN'T
On fail-only trajectories every rollout shares the same outcome, so outcome-reward baselines (Vanilla GRPO, GiGPO) get equal rewards → group variance 0 → gradient = 0 (no learning). SeRPO's per-segment rewards still vary within a trajectory → gradient ≠ 0, so the policy keeps improving even when all trajectories failed.
LOCATES THE FAILURE POINT
A single outcome scalar says only pass / fail. Per-segment rewards { r̂₁, r̂₂, r̂₃ } attribute credit along the trajectory, so a low-scoring segment pinpoints which step caused the failure (e.g. a premature action with missing API exploration) — turning an opaque rollout into a diagnosable, interpretable signal.
